## Which APK?
- **Harbor_1.0.15_android.apk**: phones and tablets (64-bit ARM).
- **Harbor_1.0.15_android-armv7.apk**: Android TVs and TV boxes (32-bit).
- **Harbor_1.0.15_android-universal.apk**: works on any device; bigger. Use it if you're not sure.

Already on 1.0.14 or older? Harbor offers this update by itself (or Settings → Updates → Check for updates).

---

##  Added

**Subtitles**
- **Every common subtitle type now plays:** SRT, WebVTT, ASS/SSA, SAMI (.smi), TTML/DFXP, MicroDVD (.sub), MPL2, SubViewer, YouTube .sbv and TMPlayer.
- Subtitles packed as .gz or .zip are unpacked. From a season pack, Harbor picks the file for the episode you're watching.

---

##  Fixed

**Subtitles**
- **Garbled subtitles:** Arabic and other subtitles saved in older text encodings showed "?" marks or letters like "ÇáÔÞÑ" on phones and tablets. Harbor now works out the encoding itself, so they show the right letters.
- A zipped subtitle pack no longer picks a readme file instead of the subtitle.

**Auto sync with Whisper**
- Auto sync worked once and then kept failing, mostly with subtitles in a different language from the audio (for example, Arabic subtitles on an English film). Whisper now listens to each full minute instead of half of it, so translated subtitles sync. It takes a little longer.
- A piece of audio that fails to load is tried once more instead of being skipped, and the audio isn't downloaded twice.

**Player**
- The Episodes list no longer draws the season buttons and episodes on top of each other.
